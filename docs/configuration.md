# 配置项说明

全部环境变量。想快速查也可以直接看 [`.env.example`](../.env.example) ——
里面每一项都写了"是什么、不填会怎样"。

本文件补充的是**分类、默认值与相互关系**。

> 一致性由脚本保证：`python scripts/check_env_docs.py`
> 会对比"代码实际读取的变量"与"文档记录的变量"，有缺失就报错。
> 这样文档不会随代码演进悄悄过期。

---

## 最少配置

| 用途 | 需要填 |
| --- | --- |
| 只处理**有字幕**视频 | `DEEPSEEK_API_KEY`、`VD_SECRET_KEY` |
| 还要处理**无字幕**视频 | 再加 `DASHSCOPE_API_KEY`、`VD_PUBLIC_BASE_URL` |
| 多人使用 | 再填 `VD_OWNER_BILI_UID`、`VD_OPERATOR_BILI_UID`、`VD_INVITED_UIDS` |

## 1. 密钥

### `DEEPSEEK_API_KEY`（必填）

负责"逐字稿 → 总结与要点"。申请：https://platform.deepseek.com/api_keys

**不填会怎样**：任务在总结阶段失败，报"未配置 DEEPSEEK_API_KEY"。

### `DEEPSEEK_BASE_URL` · 默认 `https://api.deepseek.com`

一般不用改。要接入兼容 OpenAI 协议的代理时才改。

### `DEEPSEEK_MODEL` · 默认 `deepseek-flash`

> 2026 实测：价目表当前只有 `deepseek-flash` 与 `deepseek-v4-pro`；
> 旧名 `deepseek-chat` / `deepseek-reasoner` 会被**静默降级**路由到 flash
> —— 也就是你以为换了模型，其实没有。

### `DEEPSEEK_THINKING` · 默认 `disabled`

是否开启模型的思考模式。

**为什么默认关**：DeepSeek 默认**开启**思考且 `effort=high`，而思考内容
**会占用 `max_tokens`** —— 输出预算小时，思考把预算吃光，`content`
直接返回空字符串（实测踩过）。本项目做的是"抽取 + 压缩"而非难题推理，
思考收益很低。

**打开时要相应调大输出预算**，否则会拿到空 content。

### `VD_SECRET_KEY`（必填）

加密存在磁盘上的 B 站登录凭据（SESSDATA 等 cookie）。
设计意图是"密钥与数据分离"。

生成：

```bash
python -c "import secrets;print(secrets.token_urlsafe(48))"
```

| 情况 | 后果 |
| --- | --- |
| 不填 | 无法保存登录，每次都要重新扫码 |
| **丢失** | 已保存的 B 站登录**全部失效**，需重新扫码 |
| 更换 | 同上，等同于让所有已存凭据作废 |

⚠️ 它与加密后的凭据必须**分开保存** —— 两个都泄露等于没加密。

## 2. 账号角色

<a id="账号角色"></a>

### `VD_OWNER_BILI_UID` / `VD_OPERATOR_BILI_UID`

B 站协议里"处罚权按账号走"：谁被用来发自动化请求，风险就落在谁头上。
所以本项目**强制**区分两个角色，并用**白名单**而非"优先选"：

| 角色 | 允许做什么 | 凭据是否落盘 |
| --- | --- | --- |
| **大号**（管理员）`VD_OWNER_BILI_UID` | 只决定"配额不限" | **绝不落盘、绝不用于取数** |
| **小号**（操作号）`VD_OPERATOR_BILI_UID` | **唯一**允许取数 | **唯一**存在服务器上的 |

**为什么是白名单**：如果写成"取第一个凭据"，那么一旦你用大号登录过，
它会**静默地**开始用大号抓数据，而你不会收到任何提示。

**怎么查自己的 UID**：登录 B 站后打开
https://api.bilibili.com/x/web-interface/nav ，返回 JSON 里 `data.mid` 就是。

**不填会怎样**：单人自用可以留空（登录的账号自己就是操作号），
但**凭据隔离的保证失效**。要开放给别人用，**务必填**。

### `VD_ADMIN_UIDS` · 默认空

全部管理员 UID（逗号分隔，含大号与小号）。仅用于配额与余额判定。
管理员不受每日配额与余额限制。

### `VD_OPERATOR_IS_ADMIN` · 默认 `true`

操作号是否也算管理员。设 `false` 可让操作号专门负责取数、不享受特权。

> ⚠️ **它默认是 `true`，所以用操作号测不出"非管理员"的行为。**
> 写测试或验证权限边界时必须另用一个 UID。这个坑我踩过：
> 当时以为权限测试通过了，其实测的是一个永远是管理员的账号。

## 3. Web 服务

### `VD_INVITED_UIDS` · 默认空

受邀使用者 UID（逗号分隔）。管理员自动可用，无需列在这里。
未受邀者即使扫码登录也不能提交任务。

### `VD_WEB_TRUST_LAN` · 默认 `false`

是否信任局域网来源。

默认只信任 `127.0.0.1` / `::1` / `localhost` —— 这些来源**免登录**
（凭据就在本机磁盘上，登录只是仪式感）。

⚠️ 设 `true` 的后果：**同一局域网内任何人都能免登录使用本服务**。

⚠️ 另一个容易误解的点：用 `--host 0.0.0.0` 启动后，**从本机浏览器**
访问公网地址时，数据包出去再回来，对端地址仍是 `127.0.0.1`
→ **仍然免登录**。所以在本机测"远程是否要登录"，结果可能不真实。

### `VD_TASK_REUSE_SECONDS` · 默认 `600`

同一视频在这个秒数内刚成功处理过就复用结果，避免连点两次白花 LLM 费用。
失败的任务永远可以重试。设 `0` 关闭。

### `VD_GUEST_DAILY_VIDEO_LIMIT` · 默认 `3`
### `VD_GUEST_DAILY_SECONDS_LIMIT` · 默认 `10800`

配额（按登录的 B 站账号分级，管理员不受限）。

**配额与余额是两套独立限制**，都会生效：

- **配额** —— 限次数与总时长，防滥用
- **余额** —— 只被"无字幕视频"消耗

## 4. 云语音识别（无字幕视频）

### `DASHSCOPE_API_KEY`

阿里云百炼的 API Key。申请：https://bailian.console.aliyun.com/

### `DASHSCOPE_MODEL` · 默认 `paraformer-v2`

### `VD_PUBLIC_BASE_URL`（用云 ASR 就必填）

本服务的**公网可达**地址。

**为什么必须有**：Paraformer 只接受公网可访问的 URL，而 B 站音频
因 Referer 校验外部拉不到，所以音频必须由本服务中转一次：

```
B站音频 → 本机下载 → https://你的地址/relay/<随机token> → 阿里云来取
```

| 填法 | 例子 |
| --- | --- |
| ✅ 公网 IP | `http://123.45.67.89:8788` |
| ✅ 域名 | `https://vd.example.com` |
| ❌ 回环 | `http://127.0.0.1:8788` —— 阿里云访问不到 |
| ❌ 内网 | `http://192.168.1.5:8788` —— 同上 |

填错的表现是 `FILE_403_FORBIDDEN`。自检：`python scripts/check_deploy.py --remote`

### `VD_RELAY_TTL_SECONDS` · 默认 `7200`

中转音频的最长存活时间。阿里云通常 1~3 分钟就取完，2 小时是**兜底**：
万一进程异常退出，音频也不会长期挂在公网。

### `VD_RELAY_STRICT` · 默认空（关）

开启后，没有"进行中的转写任务"时 `/relay` 一律 **403**。
让随手扫描拿不到任何东西。代价：手工调试中转 URL 时会被挡（正常现象）。

### `VD_RELAY_UA_PREFIX` · 默认空（不检查）

User-Agent 白名单前缀。填了以后只有 UA 以此开头的请求能取音频。
被拒的 UA 会记进日志，可据此确定该填什么。

> ⚠️ **想"只允许阿里云 IP 访问"是做不到的**：
> - 走 Cloudflare 隧道时，服务看到的对端是 **Cloudflare 边缘节点**，不是阿里云
> - 即使直连，阿里云拉取的出口 IP 也不固定，写死了反而挡住真请求
>
> 所以真正的防护是"**不可猜测 + 短命 + 一次性**"，不是来源限制。
> 上面两个开关都只是**收窄面**，不是安全边界。

## 5. 计费与余额

### `VD_ASR_PRICE_PER_SECOND` · 默认 `0.00008`

ASR 单价（元/秒）= 0.288 元/小时（控制台实价）。

⚠️ 阿里云的计费口径是"被判定为**语音内容**的时长"，停顿与音乐不计费
（实测语音约占 57%）。

### `VD_ASR_FREE_SECONDS_PER_MONTH` · 默认 `36000`

每月免费额度（秒 = 10 小时）。

**仅用于在余额页显示进度，不影响扣费计算** —— 因为免费额度按自然月
重置，而余额是累计的，两者不能混在一个数里算。

统计口径是**账面上的 ASR 秒数**（扣费依据的视频时长），会**略大于**
阿里云看到的用量（语音约占 57%）。所以显示"免费用完"时实际可能还剩一些
—— 保守估计，不会让你措手不及。

### `VD_INITIAL_BALANCE` · 默认 `1`

新用户初始余额（元）。给一点让新用户能试一次无字幕视频。

### `VD_BALANCE_FLOOR` · 默认取 `|VD_INITIAL_BALANCE|`

允许负债的下限（正数表示"最多欠这么多"）。

**为什么允许负数**：无字幕视频的音频一旦交给阿里云，钱就已经产生了。
与其在扣费时失败，不如允许小幅透支、把账记清楚。

判定发生在**下载音频之前**，所以余额不足时**不会**产生任何费用 ——
这个顺序是刻意的：反过来会"先把钱花掉，再发现余额不够"。

### `VD_INVITE_CREDIT` · 默认 `2.00`
### `VD_INVITE_BATCH` · 默认 `5`
### `VD_INVITE_TTL_SECONDS` · 默认 `3600`

邀请码参数：每个面额、一次生成几个、有效期。

邀请码在 `/balance` 页由管理员生成、使用者输入充值。**用一次即作废**。
