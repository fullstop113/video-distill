# 部署到云服务器

本文只讲**部署相关的配置**，不讲功能。本地开发不需要这些。

## 一、为什么云 ASR 需要一个公网地址

无字幕视频要走阿里云 Paraformer 转写。而它的接口有两个硬约束（都是实测确认的）：

| 约束 | 来源 |
| --- | --- |
| 只接受**公网可访问的 URL** | 官方 FAQ：不支持 Base64、不支持二进制流、不支持本地文件 |
| 拉不到 B 站音频 | 实测：裸请求 403、带 Referer 200 —— B 站 CDN 校验 Referer |

所以音频必须**由我们自己的服务器中转一次**：

```
你的服务器                          阿里云
   │  1. 带 Referer 下载 B 站音频
   │  2. 存进 data/relay，生成随机 token
   │  3. 交给阿里云这个地址 ──────────► http://<公网地址>/relay/<token>
   │                                  4. 阿里云来下载
   │                                  5. 转写，返回句子 + 词级时间戳
   │◄──────────────────────────────────
   │  6. 取回结果后**立即删文件**并注销 token
```

`VD_PUBLIC_BASE_URL` 就是第 3 步里那个"阿里云能访问到的根地址"。

**不配它云 ASR 就不能用** —— 代码会**明确报错**，而不是提交一个
阿里云拉不到的 `127.0.0.1` 然后返回一个语焉不详的 403。

## 二、要改的三处

### 1. 环境变量

在 `.env` 里填你的公网地址：

```bash
# 腾讯云轻量：用**公网 IP**，不是内网 10.x.x.x
VD_PUBLIC_BASE_URL=http://123.45.67.89:8788

# 有域名并配了证书的话更推荐（见第四节的 https 说明）
# VD_PUBLIC_BASE_URL=https://vd.example.com
```

### 2. 服务监听地址

默认只听 `127.0.0.1`（安全的默认值，防止本机服务意外暴露）。
要对外提供服务必须显式放开：

```bash
python scripts/serve.py --host 0.0.0.0 --port 8788
```

### 3. 云厂商安全组

腾讯云控制台 → 轻量应用服务器 → **防火墙**，加一条入站规则：

| 项 | 值 |
| --- | --- |
| 协议 | TCP |
| 端口 | 8788（或你选的端口） |
| 来源 | `0.0.0.0/0` |

**只放行你实际用的端口。** 不要图省事放行全部。

---

## 三、验证是否配对了

配好后跑一次自检（不需要真的转写）：

```bash
python scripts/check_deploy.py
```

它会检查：

- `VD_PUBLIC_BASE_URL` 是否已配、是否是公网地址（不是 `127.0.0.1`/`10.x`/`192.168.x`）
- 从**公网角度**能不能访问到 `/healthz`
- `/relay/<假token>` 是否返回 404（而不是 200 或 500）

最后一项很重要：它同时验证了"路由可达"和"不存在的 token 拿不到东西"。

## 四、安全须知（对外开放前必读）

这个服务一旦有公网地址，**下面几件事就成立了**：

### `/relay/<token>` 是免登录的

必须如此 —— 阿里云没有你的登录凭据。保护手段是：

- token 用 `secrets.token_urlsafe(24)` 生成，不可枚举
- **一次性**：取回结果后立即删文件、注销 token
- 只服务 `data/relay` 目录内的文件，文件名必须与 token 完全一致（杜绝路径穿越）

**已知局限**：如果用 `http` 而非 `https`，同一链路上的第三方可能看到 token
而抢先下载。对个人自用可接受；**对外开放时建议上 https**（腾讯云有免费证书）。

### 服务本身要设密码/限制来源

现在本机访问是**免登录**的（`is_local()` 判定）。服务器上必须确认：

- 远程访问**需要扫码登录**（这是已有的行为，但部署后要实测一次）
- 或者用安全组把来源限制到你的 IP

### 别把 `.env` 提交进版本库

`.env` 里有 DeepSeek Key、阿里云 Key、B 站凭据加密密钥。
它已在 `.gitignore` 里，**不要**为了部署方便把它拷到别处。

## 五、腾讯云轻量的配置建议

实测结论（`docs/` 里有完整数据）：**云 ASR 路线不需要 GPU，也不需要大内存**。

| 项 | 建议 | 依据 |
| --- | --- | --- |
| 内存 | **2 GB 够** | 走云 ASR 后不需要加载本地模型（本地要 5.3 GB） |
| CPU | 2 核够 | 不做本地推理，只有 Web + 队列 + HTTP |
| 磁盘 | 40 GB 够 | 音频中转是临时的，取回即删 |
| 带宽 | 5 Mbps 起 | 音频约 61 MB/百分钟，下载走服务器带宽 |

所以最便宜那档（2核2G）就够 —— 这正是选云 ASR 而不是本地 ASR 的意义。

## 六、常见错误对照

| 现象 | 原因 |
| --- | --- |
| 报"未配置 VD_PUBLIC_BASE_URL" | 就是没配，或配了空值 |
| 阿里云返回 `FILE_403_FORBIDDEN` | 公网地址填错了（填了内网 IP / `127.0.0.1`），或安全组没放行 |
| `check_deploy.py` 说公网访问不到 | 服务没监听 `0.0.0.0`，或安全组没放行，或本机防火墙拦了 |
| 本机能开、外网打不开 | 99% 是安全组；其次是 `--host` 没改 |
